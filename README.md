Personal engineering portfolio showcasing technical projects, professional training, and practical work in AI systems, data pipelines, and workflow automation.

### Featured Projects
- **[Xare AI Platform](https://xare-ai.vercel.app)** — Multimodal AI application and orchestration platform featuring intelligent model routing, multi-tier fallback workflows across AI services, document processing, and real-time voice streaming.

### Tech Stack & Features
- **Frontend & Styling:** Semantic HTML5, Tailwind CSS, Interactive Particle Canvas, Glassmorphism, 3D Tilt Cards.
- **Internationalization:** Multi-language support (English, Arabic, Japanese, Turkish) with automatic RTL/LTR direction switching.
- **Accessibility & Performance:** Screen reader labels, keyboard focus management, skip-link navigation, and zero third-party framework overhead.
